# ملف التحقيق الجنائي السري LS-001 | LOS SANTOS POLICE DEPARTMENT

الموقع الإلكتروني الاستخباراتي والشرطي الرسمي لعرض ملف القضية الجنائية **LS-001** التابعة لـ **مديرية شرطة لوس سانتوس (LSPD)** — قضية ألكساندر بتروف (الاسم الحركي «لوسفر»)، والتحقيق المتعلق بالمنظمة السرية بقيادة «البروفيسور» وواقعة الإيهام بإعدام بتروف وتبرئة الضابط ريك جونير.

المشروع مبني بالكامل كـ **موقع ثابت (Static Website)** باستخدام تقنيات الويب القياسية الخالصة (HTML5 / CSS3 / Vanilla JavaScript)، دون أي اعتماد على أطر عمل، معالجات بناء، أو خوادم خلفية أو قواعد بيانات.

## 🚀 طريقة النشر والاستضافة على GitHub Pages

المشروع جاهز 100% للرفع والتشغيل الفوري:

1. أنشئ مستودعًا جديدًا على حسابك في GitHub (مثال: `lspd-case-ls001`).
2. ارفع كافة ملفات ومجلدات المشروع إلى المستودع (مع الحفاظ على بنية المجلدات وملف `.nojekyll`).
3. توجه إلى إعدادات المستودع (**Settings**) في GitHub.
4. اختر تبويب **Pages** من القائمة الجانبية.
5. أسفل خيار **Build and deployment**:
   - اختر **Source**: `Deploy from a branch`
   - اختر **Branch**: `main` (أو `master`) مع اختيار المجلد `/ (root)`.
   - انقر على **Save**.
6. خلال دقيقة واحدة، سيظهر لك الرابط المباشر للموقع المنشور جاهزًا للمعاينة والمشاركة عالميًا.

> **ملاحظة تشغيل محلي:** يمكنك أيضًا فتح ملف `index.html` مباشرة على أي جهاز كمبيوتر أو متصفح وسيعمل الموقع بالكامل دون الحاجة لأي اتصال بالإنترنت أو برامج خادم.

## 🎥 دليل إدراج الصور ومقاطع الفيديو الجديدة

الموقع مبرمج بطريقة مرنة تعتمد على مصفوفة بيانات مركزية في ملف `script.js` دون الحاجة إلى لوحة تحكم أو قاعدة بيانات:

### 1. لإضافة أو استبدال صورة شخصية أو دليل:
1. ضع ملف الصورة داخل مجلد `assets/images/`.
2. افتح ملف `script.js` وابحث عن مصفوفة `EVIDENCE_DATA`.
3. حدد القيد المناسب أو أضف قيدًا جديدًا وضع مسار الملف:
   ```javascript
   filePath: "assets/images/اسم_الصورة_الجديدة.png",
   isAvailable: true,
   ```

### 2. لإضافة مقطع فيديو جديد:
1. ضع ملف الفيديو بصيغة MP4 القياسية داخل مجلد `assets/videos/`.
2. في ملف `script.js`، حدد قيد الفيديو المطلوب وضع المسار النسبي:
   ```javascript
   filePath: "assets/videos/اسم_الفيديو.mp4",
   isAvailable: true,
   status: "مؤكد ومحرز جنائياً",
   ```
3. سيتحول مشغل الفيديو في الموقع تلقائيًا من حالة الانتظار إلى مشغل فيديو HTML5 نشط، وستتحدث عدادات الإحصائيات في الصفحة الرئيسية تلقائيًا.

### ⚠️ تنبيه بخصوص أحجام ملفات الفيديو الكبيرة:
منصة GitHub تضع حدًا أقصى لحجم الملف الفردي (100 ميجابايت). إذا كان لديك مقطع فيديو كبير جدًا، يُنصح بضغطه باستخدام ترميز H.264 القياسي لضمان عدم تجاوز الحد الأقصى للملفات عند الرفع إلى المستودع.

## ⚖️ أقسام القضية المتضمنة في الموقع

1. **لوحة القضية (Dashboard):** البطاقة التعريفية للهدف ألكساندر بتروف («لوسفر»)، شارة المطلوب الأول، والإحصائيات التراكمية الحية.
2. **ملخص التحقيق:** عرض وقائع القضية وتطوير الروبوتات وهجمات القنص واختطاف ريك جونير وكشف التناقض الجوهري.
3. **الشخصيات المرتبطة:** بطاقات أمنية لكل من (ألكساندر بتروف، البروفيسور، الضابط ريك جونير، ونائب رئيس الشرطة ريموند ريد).
4. **حقيقة إعدام لوسفر (THE FAKE EXECUTION):** إعادة بناء تسلسل الواقعة بالأدلة، بطاقة النتيجة الرسمية، ومشغلات الفيديو المستقلة الجاهزة للتسجيلات.
5. **معرض الأدلة المصورة والرقمية:** مصنف وفق 9 فئات مع محرك بحث فوري، فلاتر حسب نوع الملف والفئة وحالة التحقق، ونافذة تكبير وفحص فني.
6. **جدول التهم الجنائية:** 6 تهم رئيسية مع تحديد الشخصية المعنية، الأدلة المرتبطة، ونتيجة التحقيق («أدلة داعمة للاتهام»).
7. **الخط الزمني للأحداث:** 12 حدثاً متسلسلاً مع إمكانية النقر للانتقال مباشرة للدليل المرتبط.
8. **التحقيق المشترك:** التنسيق الاستخباراتي مع FBI وCIA، والبطاقة الرسمية المعتمدة لـ «الجهة الناقلة للمعلومات».
9. **التقرير النهائي للتحقيق:** الخلاصة الإجرائية الشاملة، الصياغة القانونية المعتمدة، وخانة التوقيع والاعتماد الشرطي مع زر طباعة التقرير أو حفظه كملف PDF رسمي.
